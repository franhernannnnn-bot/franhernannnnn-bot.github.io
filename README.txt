PROYECTO ZACAHUIL HUASTECO - VERSIÓN 2
========================================
Proyecto académico para Adobe Dreamweaver.

PÁGINAS:
index.html       Inicio + SEO + buscador
historia.html    Historia y tradición
productos.html   Catálogo + buscador + categorías + carrito
promociones.html Ofertas
galeria.html     Galería (sustituir placeholders por fotos)
carrito.html     Carrito con localStorage
pedidos.html     Formulario
contacto.html    Información de contacto

ARCHIVOS:
css/style.css
js/script.js
js/carrito.js
img/

IMPORTANTE:
- Los precios, teléfono, correo y WhatsApp son demostrativos.
- Cambia el número del enlace de WhatsApp en los HTML por uno real si lo necesitas.
- Agrega fotografías en img/ y reemplaza los bloques de galería por <img>.
- El carrito funciona en el navegador usando localStorage; no procesa pagos reales.
- Para Dreamweaver: Sitio > Nuevo sitio > selecciona esta carpeta como carpeta raíz.
